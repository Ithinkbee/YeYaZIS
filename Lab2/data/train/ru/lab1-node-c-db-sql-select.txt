# Язык SQL и выборка данных

Язык SQL служит для описания структуры данных и выполнения запросов к базе данных. Оператор SELECT выбирает столбцы, WHERE задаёт условие отбора строк, ORDER BY сортирует результат, а LIMIT ограничивает число возвращаемых записей. Соединение JOIN объединяет строки нескольких таблиц по условию, чаще всего по совпадению первичного и внешнего ключей.

Агрегатные функции COUNT, SUM и AVG вместе с GROUP BY подсчитывают итоги по группам строк. Вложенный запрос позволяет использовать результат одной выборки как условие другой, но нередко его выгоднее переписать через соединение.
