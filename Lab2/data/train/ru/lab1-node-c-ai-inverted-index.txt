# Инвертированный индекс

Инвертированный индекс хранит для каждого термина список документов, в которых он встречается, вместе с частотой и весом. Такая структура позволяет не просматривать коллекцию целиком: система берёт списки только для слов запроса и объединяет их. Словарь терминов обычно держат в памяти, а списки вхождений — на диске в сжатом виде.

Построение индекса включает разбиение текста на слова, приведение их к нормальной форме и удаление стоп-слов. При добавлении новых документов меняется число документов коллекции, поэтому веса терминов приходится пересчитывать.
