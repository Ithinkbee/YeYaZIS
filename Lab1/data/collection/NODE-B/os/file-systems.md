# Файловые системы NTFS и ext4

Файловая система определяет, как данные размещаются на диске и как ведётся учёт свободного места. NTFS применяется в Windows и поддерживает журналирование, права доступа, сжатие и шифрование файлов. Файловая система ext4 используется в Linux, хранит метаданные в индексных дескрипторах и хорошо работает с большими томами.

Журнал операций позволяет восстановить целостность после внезапного отключения питания. Фрагментация файлов замедляет чтение на механических дисках, а на твердотельных накопителях её влияние незначительно.
