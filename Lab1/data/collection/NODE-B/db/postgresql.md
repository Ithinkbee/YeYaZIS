# Серверная СУБД PostgreSQL

PostgreSQL — свободная серверная система управления базами данных с богатым набором типов и расширений. Она поддерживает транзакции, оконные функции, хранение документов JSON и полнотекстовый поиск с учётом морфологии. Механизм многоверсионности позволяет читателям не блокировать писателей, что хорошо масштабируется под нагрузкой.

Планировщик запросов выбирает способ выполнения на основе статистики распределения значений в столбцах. Репликация на резервный сервер обеспечивает отказоустойчивость и позволяет распределять нагрузку чтения.
