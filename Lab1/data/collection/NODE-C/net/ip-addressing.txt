IP-адресация и разбиение на подсети

Каждому узлу локальной сети назначается IP-адрес, состоящий из номера сети и номера узла. Маска подсети показывает, какая часть адреса относится к сети: например, маска 255. 255. 255. 0 оставляет под адреса узлов последний октет. Для внутренних сетей зарезервированы частные диапазоны 10. 0. 0. 0, 172.

16. 0. 0 и 192. 168. 0. 0, которые не маршрутизируются в интернете. Разбиение на подсети уменьшает широковещательный домен и упорядочивает адресное пространство предприятия. Проверить настройки узла можно командой ipconfig в Windows или ip address в Linux, а доступность соседа — командой ping.
