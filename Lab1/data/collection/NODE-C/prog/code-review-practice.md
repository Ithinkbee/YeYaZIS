# Обзор кода и поддержание его качества

Обзор кода — чтение изменений одним разработчиком перед их включением в основную ветку проекта. Он находит ошибки, которые не ловят тесты: неверные предположения, неучтённые случаи, непонятные названия. Замечания формулируют по существу кода, а не по личности автора, и отделяют обязательные исправления от пожеланий.

Небольшой объём изменений просматривается внимательно, а обзор крупной переделки быстро становится формальным. Единый стиль оформления и автоматические проверки снимают с обсуждения споры о расстановке пробелов и длине строк. Побочная польза обзора — распространение знаний о проекте между участниками команды.
