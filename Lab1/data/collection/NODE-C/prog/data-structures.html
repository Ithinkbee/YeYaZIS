Структуры данных: списки, деревья и хеш-таблицы

Структура данных определяет способ хранения элементов и набор доступных над ними операций. Массив даёт мгновенный доступ по номеру, но вставка в середину требует сдвига остальных элементов. Связный список вставляет элемент за постоянное время, зато поиск в нём последовательный.

Хеш-таблица находит значение по ключу практически за постоянное время, вычисляя положение элемента функцией свёртки. Двоичное дерево поиска хранит элементы упорядоченно и позволяет быстро находить диапазоны значений. Выбор структуры определяется тем, какие операции выполняются чаще: именно на хеш-таблицах и деревьях строятся словари и индексы прикладных систем.
