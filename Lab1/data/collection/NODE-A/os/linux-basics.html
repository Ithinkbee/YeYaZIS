Основы работы в операционной системе Linux

Linux — это семейство операционных систем с открытым исходным кодом, широко применяемое на серверах. Работа ведётся через командную оболочку: команда ls выводит содержимое каталога, cd меняет текущий каталог, grep ищет строки в файлах. Права доступа задаются для владельца, группы и остальных пользователей и меняются командой chmod.

Пакетный менеджер устанавливает и обновляет программы из репозитория, разрешая зависимости автоматически. Файлы настроек хранятся в виде обычного текста в каталоге etc, что упрощает резервное копирование и сравнение конфигураций.
