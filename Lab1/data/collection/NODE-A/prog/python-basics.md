# Основы языка программирования Python

Python — язык программирования с динамической типизацией и лаконичным синтаксисом, в котором блоки кода выделяются отступами. Основные встроенные типы данных: число, строка, список, кортеж, множество и словарь. Функция объявляется словом def и может возвращать несколько значений сразу.

Списковое включение позволяет построить новый список из существующего одной строкой вместо цикла. Обработка исключений отделяет основной ход программы от разбора ошибочных ситуаций. Обширная стандартная библиотека закрывает работу с файлами, датами, сетью и текстом без установки дополнительных пакетов, а виртуальное окружение изолирует зависимости отдельного проекта.
