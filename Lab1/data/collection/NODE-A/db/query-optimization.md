# Оптимизация выполнения запросов

Оптимизация начинается с изучения плана выполнения запроса, который показывает порядок соединения таблиц и способ доступа к данным. Полный просмотр большой таблицы вместо обращения по индексу — самая частая причина медленной работы. Выборка только нужных столбцов вместо звёздочки уменьшает объём передаваемых данных.

Условие, обёрнутое функцией, мешает использовать индекс, поэтому его переписывают в эквивалентный вид. Актуальная статистика распределения значений помогает планировщику правильно оценивать число строк и выбирать удачный план.
