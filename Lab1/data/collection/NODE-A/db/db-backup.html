Резервное копирование баз данных

Резервная копия базы данных должна быть согласованной: копирование файлов работающей СУБД без остановки записи даёт непригодный результат. Логическая выгрузка сохраняет данные в виде набора команд SQL и удобна для переноса между версиями. Физическая копия файлов вместе с журналом транзакций восстанавливается быстрее и позволяет откатиться на произвольный момент времени.

Регулярность копирования определяется допустимым объёмом потерь: если потерять больше часа работы нельзя, копии делают чаще. Восстановление обязательно проверяют на тестовом сервере, иначе о непригодности копии узнают в худший момент.
