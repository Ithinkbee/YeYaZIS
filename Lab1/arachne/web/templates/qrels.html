Как размечать

  1. Выберите слева запрос — система покажет top-{{ top_k }} своей выдачи.
  2. Для каждого документа поставьте оценку: 2 — прямо отвечает, 1 — частично полезен, 0 — не по теме.
  3. Оценка 0 так же важна, как и положительная: без явно нерелевантных документов метрика bpref вырождается.
  4. Сохраните разметку в CSV, чтобы она пережила пересборку базы.

Документы сопоставляются с оценками по имени файла, поэтому повторный обход локальной сети разметку не ломает.
