# «Слухач» — распознавание речи и голосовое управление

Лабораторная работа № 9, **вариант 7**:

| параметр | значение |
|---|---|
| система | анализа речи |
| язык | немецкий; дополнительно — русский |
| предметная область | сочинения по литературе |

Система слушает микрофон, сама находит в звуке речь, распознаёт её и
реагирует: выполняет одну из заданных операций над сочинениями по литературе
— открывает сочинение, читает абзац вслух, ищет слово, называет объём — и о
каждом шаге сообщает. Фразу, для которой операции нет, она повторяет вслух.
Ответ звучит голосом и одновременно появляется текстом в облачке паука
Пафнутия — он, как и в прошлых работах, сидит в углу страницы, а здесь стал
голосом системы.

Сверх задания:

* **фразы-пасхалки** — администратор вписывает ключевую фразу и ответ на
  неё; услышав такую фразу, система не повторяет её, а произносит ответ;
* **прогулка с Пафнутием** — игра, в которой паук слушается не слов, а
  громкости: от тихого голоса идёт, от громкого подпрыгивает;
* **новая модель Пафнутия** — с брюшком, глазами и ногами, которые
  вычисляются, а не нарисованы.

Слухач — тот, кто на слух ловит и разбирает сигнал: в старину слухачи
слушали подкопы под крепостной стеной, позже — эфир. Название продолжает
ряд «Арахна», «Толмач», «Изборник».

## Быстрый старт

```bash
pip install -r requirements.txt
python tools/get_models.py        # модели Vosk: 2 × 45 МБ, один раз
python run.py
```

Откроется браузер на `http://127.0.0.1:8097/`. Нажмите «Слушать», разрешите
микрофон и скажите по-немецки: *„Liste der Aufsätze“*.

```bash
python run.py --no-browser               # только сервер
python run.py --language ru              # начать с русского языка
python run.py --port 8080                # другой порт
python run.py --admin-password секрет    # свой пароль администратора
```

Микрофон браузер даёт только защищённым страницам. Адреса `127.0.0.1` и
`localhost` считаются защищёнными и без HTTPS, поэтому открывать систему
нужно по одному из них.

| переменная | значение |
|---|---|
| `SLUHACH_LANGUAGE` | язык речи при запуске: `de` (по умолчанию) или `ru` |
| `SLUHACH_ADMIN_LOGIN` | имя администратора, по умолчанию `admin` |
| `SLUHACH_ADMIN_PASSWORD` | пароль администратора, по умолчанию `pafnuty` |
| `SLUHACH_COMPANION` | `0` — убрать паука Пафнутия и его игру |
| `SLUHACH_HOST`, `SLUHACH_PORT` | адрес и порт сервера (`127.0.0.1`, `8097`) |
| `SLUHACH_MODELS_DIR` | каталог моделей Vosk (по умолчанию `models/`) |
| `SLUHACH_STATE_DIR` | где хранить список операций и пасхалки (по умолчанию `data/`) |

Нужны Chrome или Edge — в других браузерах система не проверялась — и
голоса немецкого и русского языков для ответа: в Windows они ставятся в
«Параметрах» → «Время и язык» → «Речь».

## Как система реагирует на речь

1. **Звук.** Браузер снимает звук с микрофона, приводит его к 16 кГц
   (обработчик `capture-worklet.js` в звуковом потоке браузера) и кусками по
   100 мс шлёт на сервер по WebSocket.
2. **Речь в сигнале.** Сигнал режется на кадры по 20 мс, у каждого считается
   уровень `L = 20 · lg(RMS / 32768)` дБ. Шум комнаты `N` оценивается, пока
   человек молчит: `N ← N + α · (L − N)`, вверх медленно (α = 0,04), вниз
   быстро (α = 0,25). Фраза **начинается**, когда из пяти кадров подряд три
   громче `max(N + 9, −50)` дБ, и **кончается** после 700 мс кадров тише
   `max(N + 5, −53)` дБ. Распознавателю отдаются и 300 мс звука перед началом —
   иначе пропал бы первый согласный. Всплеск короче 160 мс фразой не считается;
   звук без паузы обрывается через 15 с и становится новым уровнем шума.
3. **Распознавание.** Кадры фразы идут в распознаватель Vosk (Kaldi:
   акустическая модель TDNN и декодер на взвешенных конечных автоматах).
   Промежуточный текст запрашивается каждые 100 мс и сразу показывается;
   окончательный — после паузы. Если слов в «фразе» не оказалось, порог
   детектора поднимается: это был шум.
4. **Приведение к одному виду.** Строчные буквы, без знаков препинания, «ё»
   как «е», умлауты как „ae“, „oe“, „ue“, „ß“ как „ss“. Обращение и слова
   вежливости («Пафнутий», «пожалуйста», „bitte“) отбрасываются.
5. **Пасхалки.** Если фраза похожа на одну из ключевых не меньше чем на 80 %,
   система произносит ответ на неё.
6. **Операции.** Фраза сравнивается с фразами всех включённых операций.
   Мера сходства — `1 − d / max(|a|, |b|)`, где `d` — расстояние Левенштейна
   между строками. Операция выбрана, если сходство не ниже 75 % (для команд из
   пяти и менее букв — 80 %: «стоп», „halt“ должны прозвучать точно). У
   команды с параметром сравнивается только начало фразы — столько слов,
   сколько в команде, плюс-минус одно на случай склейки; остальное — параметр.
   При равном сходстве побеждает фраза с большим числом слов команды.
7. **Повтор.** Ничего не подошло — система повторяет услышанное. Вздохи и
   обрывки («hm», «э») она не повторяет.
8. **Ответ.** Текст ответа читает синтезатор речи браузера — по частям не
   длиннее 220 знаков, по границам предложений — и показывает Пафнутий. Пока
   звучит ответ, микрофон не слушается: иначе система распознала бы
   собственный голос.

Состояние разговора — язык, открытое сочинение, текущий абзац — хранит
страница и присылает с каждой фразой. Сервер от запроса к запросу ничего не
помнит, поэтому реакция — обычная функция от фразы и состояния
(`reactions.Reactor.react`), и её удобно проверять.

Распознавать можно и вторым способом — распознавателем самого браузера (Web
Speech API; настройка «Распознаёт»). Он есть в Chrome и Edge и работает
только с интернетом; дальше фраза идёт тем же путём с шага 4.

Параметры понимаются так:

* **номер** — цифрами («3») или словами, количественными и порядковыми:
  «три», «третье», «двадцать три», „drei“, „dritten“, „dreiundzwanzig“.
  Числительное, расслышанное с ошибкой («sie bin» вместо „sieben“),
  восстанавливается по сходству с числительными языка;
* **название** — слова названия, имя героя или автора в любом падеже: «про
  Онегина», «о Мастере и Маргарите», „über Kafka“, „die Räuber“;
* **слово** — ищется во всех формах, по основе: «дуэль» найдёт «дуэли»,
  „Räuber“ — „Räubern“ и „Räuberbande“.

Операция «замолчать» слышна, только если включено «слушать и во время
ответа» (в наушниках); иначе ответ обрывают кнопка «Замолчать» и клавиша Esc.

## Фразы-пасхалки и вход администратора

Обычный пользователь говорит с системой, но менять пасхалки не может: это
право администратора.

1. Нажмите **«Вход администратора»** внизу любой страницы — или откройте
   `http://127.0.0.1:8097/admin` — и введите имя и пароль. По умолчанию это
   `admin` и `pafnuty`; при запуске система показывает их в консоли. Свой
   пароль: `python run.py --admin-password …` или переменная
   `SLUHACH_ADMIN_PASSWORD`.
2. Откроется окно **«Тайник Пафнутия»** с таблицей пасхалок. Впишите ключевую
   фразу и фразу-ответ — например «Сколько стоит слон?» и «Вам тут не рынок и
   не цирк» — и нажмите «Добавить». Строку можно исправить и сохранить или
   удалить. Поле «Проверить» показывает, сработает ли пасхалка на фразу, — без
   микрофона.
3. Пока вы не вышли, в меню есть пункт «Тайник». «Выйти» — в окне и внизу
   страницы.

Окно открывается ещё пятью быстрыми щелчками по пауку и сочетанием
Ctrl+Alt+P. Без входа оно показывает только вопрос об имени и пароле.

Как это устроено:

* после верного входа сервер выдаёт случайный ключ сеанса и кладёт его в
  cookie, недоступную сценариям страницы (`HttpOnly`, `SameSite=Strict`);
  без ключа `/api/eggs` отвечает 401 — и на чтение, и на запись. В разметке
  страниц пасхалок нет;
* имя и пароль сравниваются за постоянное время, ответ на ошибку не говорит,
  что именно неверно; после пяти ошибок подряд вход закрыт на 30 секунд;
* вход действует 12 часов и до перезапуска системы: ключи сеансов живут в
  памяти;
* пасхалки хранятся в `data/eggs.json` и действуют сразу. Пока файла нет,
  действуют две пасхалки по умолчанию — про слона, на русском и на немецком;
* ключевая фраза узнаётся без знаков препинания, с обращением («Пафнутий,
  сколько стоит слон?») и с ошибкой в букве; язык определяется по алфавиту,
  ответ читается голосом того языка, на котором написан.

Пароль по умолчанию годится только для своего компьютера: система слушает
адрес `127.0.0.1`, и по сети в неё не войти.

## Результаты

`python tools/evaluate.py` — все числа в `report/evaluation.json`, графики
`report/eval_*.png`; их показывает страница «Проверка».

Проверочный набор — 237 фраз: все фразы всех операций с подставленными
параметрами (159 команд), 76 предложений из сочинений и 2 пасхалки. Каждую
фразу произносит синтезатор речи Windows: по-немецки — голоса Hedda, Katja и
Stefan, по-русски — Irina и Pavel; всего 592 записи. Запись дополняется
тишиной и белым шумом и проходит тот же путь, что звук с микрофона: детектор
речи, потоковое распознавание, выбор операции. Четыре условия — без шума и с
отношением сигнал/шум 20, 10 и 5 дБ — дают 2368 испытаний.

Главная мера — **верная реакция**: реакция на распознанную фразу та же, что
на её эталонный текст (та же операция с тем же итогом — то же сочинение,
абзац, язык, найденное слово), и это именно та операция, которой принадлежит
фраза.

### Выводы

1. **Нечёткое сопоставление делает своё дело.** Распознаватель ошибся в 67
   разных командах («ließ vor» вместо «lies vor», «сочинении» вместо
   «сочинение», «wieviele» вместо «wie viele»), но к неверной реакции привели
   только шесть ошибок. Остальные исправлены сходством букв, пропуском слова
   «слово» в параметре и восстановлением числительных.
2. **Оставшиеся ошибки — это другие настоящие слова**, и сходством их не
   исправить: «stopp» → «staub» (у двух голосов из трёх), «Effi» → «f e» (имени
   нет в словаре модели), «абзацу семь» → «абзаца восемь», «про Онегин» → «про
   не ген». От них помогает выбор фраз: «halt» и «hör auf» вместо «stopp»,
   «абзац номер семь», номер сочинения вместо редкого имени. Услышанное можно
   и просто вписать как ещё одну фразу операции.
3. **Русская модель ошибается в словах вдвое чаще немецкой** (18 % против
   7 % на командах), но реагирует система по-русски не хуже: ошибки — в
   окончаниях, а их сходство прощает.
4. **Шум до 20 дБ почти не мешает, при 10 дБ теряется пятая часть команд,
   при 5 дБ система не работает** — и прежде всего потому, что детектор не
   замечает речь: порог начала фразы стоит на 9 дБ выше шума, а речь громче
   шума только на 5.
5. **Голоса ведут себя по-разному:** мужские голоса шум почти не замечают
   (95 % и 94 % при 10 дБ), женские теряют до трети команд.
6. **Предел точности задаёт словарь модели.** Малая модель знает слова, а не
   буквы: имя вне словаря она заменяет похожими словами.

### Что улучшило бы систему

* детектор речи не по одной энергии, а по спектру или нейросетевой (Silero
  VAD) — это вернуло бы фразы, которые теряются при 5–10 дБ;
* шумоподавление перед распознаванием;
* большие модели Vosk (1,8 ГБ на язык) или Whisper — меньше ошибок в словах,
  особенно в русских окончаниях и именах; цена — память и задержка;
* ограничение словаря распознавателя фразами операций (Vosk это умеет) для
  режима «только команды» — ценой свободной речи;
* подавление собственного голоса системы, чтобы её можно было перебивать без
  наушников.

### Чего проверка не показывает

Синтезированная речь ровнее живой: в ней нет оговорок, акцента, эха комнаты
и дешёвого микрофона, а белый шум проще настоящего. Числа выше — верхняя
оценка; с микрофона ошибок будет больше. Зато проверка повторима: её можно
запустить после любой правки и сравнить числа.

## Прогулка с Пафнутием

Страница `/walk`. Паук идёт по карте слева направо и слушается громкости
голоса — слов игра не распознаёт. Механика взята у игр, управляемых голосом
(«Yasuhati», «Scream Go Hero»).

* **Тихий голос — шаг.** Паук идёт, пока слышит голос; замолчали — стоит.
* **Громкий голос — прыжок**, тем выше и дальше, чем громче: от 62 до 159
  единиц в высоту и от 97 до 156 в длину. Пугается паук один раз — чтобы
  прыгнуть снова, голос должен сначала стихнуть; иначе непрерывный крик
  превратился бы в скачку.
* **В полёте не молчите:** вперёд паук летит, только пока звучит голос.
* **Вода** — только прыжком; искупавшись, паук возвращается к последней
  метке. **Овраг** не страшен, но шагом из него не выйти. Так же с высокой
  ступенькой.
* На финише — звёзды: три, если ни разу не искупался.

Перед игрой голос настраивается в два шага. Полторы секунды паук слушает
тишину — это шум комнаты (медиана замеров). Потом ждёт, пока игрок
заговорит вполголоса, две с половиной секунды слушает его и берёт уровень,
громче которого пятая часть звуков голоса, — так оцениваются ударные
гласные; кашель и стук голосом не считаются. По этим двум числам
ставятся пороги: **идти** — посередине между шумом и голосом, но не дальше
14 дБ от голоса; **прыгать** — на 9 дБ громче спокойного голоса; самый
сильный прыжок — ещё на 10 дБ громче, но не выше −5 дБ, где микрофон уже
обрезает звук. По одному шуму комнаты пороги пришлось бы угадывать: в тихой
комнате порог прыжка оказался бы ниже обычной речи. Так пороги ставятся,
только если голоса при настройке не было (идти — на 12 дБ громче шума,
прыгать — ещё на 16 дБ), и игра об этом говорит.

Пороги видны на столбике громкости и поправляются ползунками; если голос
доходит слишком тихим или слишком громким, игра советует поправить усиление
микрофона. Обработка сигнала браузером (автоматическое усиление, подавление
шума) для игры выключена: она выравнивает тихий и громкий голос. Без
микрофона паук слушается клавиш: → — идти, пробел — прыгать.

Три карты и случайная. Карта записана строкой — `G300 W55 G230 U22 …`: земля,
вода, овраг, ступень, метка, финиш. Проходимость каждой карты, включая 120
случайных, проверяется тестом: по ней идёт «игрок», который перед
препятствием кричит с наименьшей достаточной силой.

`SLUHACH_COMPANION=0` убирает паука, игру и операцию «открыть игру»;
распознавание, операции и пасхалки работают по-прежнему, ответы остаются в
журнале (проверяется тестом в отдельном процессе).

### Новая модель Пафнутия

В прошлых работах паук был двумя кружками с восемью чёрточками. Теперь у
него брюшко с крестом, как у крестовика, головогрудь с двумя большими и двумя
малыми глазами, рот, щёки, педипальпы и восемь ног из бедра и голени с
коленом. Ноги не нарисованы: у каждой задана точка крепления и длины
сегментов, а колено вычисляется по положению стопы (обратная кинематика двух
звеньев). Поэтому одна модель (`pafnuty.js`, SVG) и висит на нити в углу, и
шагает по карте двумя четвёрками ног, и растопыривает ноги в прыжке, и
нащупывает стопами край ступеньки.

В углу страницы паук показывает, чем занята система: спит, пока микрофон
выключен; поднимает передние ноги, когда слышит речь (пауки и правда слышат
ногами); смотрит вверх, пока фраза распознаётся; шевелит ртом, пока звучит
ответ. Зрачки следят за указателем мыши.

## Сценарии и тесты

```bash
python tools/get_models.py            # модели Vosk
python tools/evaluate.py              # проверка (≈ 4 минуты) и графики
python tools/evaluate.py --quick      # один голос на язык, два условия (≈ 40 с)
python tools/screenshots.py           # снимки экрана (система должна работать)
python tools/make_test_audio.py       # записи для тестов заново
python -m pytest tests -q             # тесты
```

Тесты проверяют нормализацию, расстояние Левенштейна, WER и числительные;
счёт предложений и поиск слов и названий; сопоставление — каждая фраза каждой
операции вызывает свою операцию, ошибки распознавателя её не меняют, а
предложения из сочинений командами не становятся; задание списка операций и
его хранение; реакцию на каждую операцию на обоих языках; пасхалки и вход
администратора — блокировку, срок действия, отказ без ключа; детектор речи
на собранных вручную сигналах — шум, фраза, пауза внутри фразы, щелчок,
непрерывный гул; распознавание записей и поток событий слушателя;
веб-интерфейс вместе с WebSocket; выключатель паука; сам проверочный набор.

Правила, написанные на JavaScript, проверяются в node:
`tests/walk_rules.test.js` (физика прогулки, проходимость карт, настройка
порогов по шуму и голосу), `tests/pafnuty_model.test.js` (геометрия ног),
`tests/voice_rules.test.js`
(деление ответа на части, выбор голоса, шкала громкости). Без node эти три
проверки пропускаются; без пакета vosk или моделей пропускаются тесты
распознавания.

Список операций и пасхалки тесты пишут во временный каталог, настоящие
настройки не трогают.

В браузере без окна (Chrome, протокол DevTools) проверено: пульт на фразах с
клавиатуры; весь путь от микрофона до ответа — микрофон заменяла запись;
окно администратора; игра — и с клавиатуры, и голосом, который заменяла
запись из шума, тихого и громкого тона: настройка в два шага (в том числе с
молчащим игроком, слишком тихим и слишком громким микрофоном), шаг от тихого
голоса и прыжок от громкого. Распознавание самим браузером проверено только
с подставным распознавателем: настоящей службы в браузере без окна нет.
С живым микрофоном система не проверялась.
