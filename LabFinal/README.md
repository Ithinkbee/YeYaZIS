# «Поклон» — прощальный ролик к курсу ЕЯзИИС

Не лабораторная, а то, чем они заканчиваются. Лифт поднимается по шахте, мимо
проезжают поющие паучата — дети Пафнутия, паука из всех наших работ. На этажах
висят таблички, по две на этаж: «Арахна» и «Толмач», «Изборник» и «Драгоман»,
«Глашатай» и «Слухач». Под каждой стоят паучата с вещами этой работы: с лупой,
с табличками «RU ? DE», со свитком и ножницами, с рогом, с микрофоном. Когда в
музыке вступает большой хор, шахта раскрывается в зал: там
дирижирует сам Пафнутий в бабочке, а за ним поёт Большой паук, который в кадр
не помещается. Наверху лифт выходит на свет — на страницу со словами
благодарности.

Сцена сделана по мотивам финала Portal 2; музыка — запись, которую вы кладёте
сами.

## Запуск

```
python run.py
```

Откроется браузер с кнопкой вызова лифта. Ставить ничего не нужно: сервер
написан на стандартной библиотеке Python, ролик рисуется в браузере (Chrome,
Edge, Firefox).

| ключ | что делает |
|---|---|
| `--music запись.mp3` | своя запись или папка с ней (иначе — папка `music/`) |
| `--port 8080` | другой порт (по умолчанию 8100) |
| `--no-browser` | не открывать браузер |

**Перед показом:** `F` — во весь экран, потом кнопка лифта или пробел.

| клавиша | действие |
|---|---|
| пробел | пауза и продолжение |
| `F` | во весь экран |
| `←` `→` | перемотка на 5 секунд (с `Shift` — на одну) |
| `Home` | с начала |
| `M` | без звука |
| `R` | репетиция |
| `Esc` | к кнопке вызова |

## Музыка

Записи в папке нет и в репозиторий она не попадает: музыка чужая. Есть два
способа её добавить:

- положить файл (mp3, m4a, ogg, flac, wav) в папку [`music/`](music/);
- перетащить файл на страницу ролика — он сохранится в ту же папку.

Без записи ролик идёт в тишине — так удобно посмотреть его целиком заранее.

### Как ролик попадает в музыку

Расписание не привязано к секундомеру. Запись сначала прослушивается целиком:
тридцать раз в секунду считаются громкость и три полосы спектра. Дальше:

- **большой хор** — самая громкая протяжённая часть записи. Её начало и конец —
  две метки, от которых отсчитывается всё остальное: когда лифт тормозит перед
  залом, когда вспыхивает свет, когда кабина уходит вверх;
- **рты** открываются по полосам спектра: паучата поют на верхах, хор — на
  середине, Большой паук — на басах;
- **высота, на которой висит каждый паук**, считается через путь лифта: «в
  центре кадра на двадцатой секунде» значит «там, где кабина будет на двадцатой
  секунде». Сдвинулись метки — шахта расставилась заново;
- **этажи** встают так, чтобы не наезжать друг на друга. Если хор вступает рано
  и до зала мало высоты, солистка в начале едет рядом с кабиной меньше, а этажи
  стоят плотнее; если записи после хора хватает, последний этаж уходит за зал.

### Репетиция

Найденные метки стоит один раз проверить на слух. Клавиша `R` открывает ленту
времени с громкостью записи и двумя метками:

- метку можно перетащить мышью или поставить в текущем месте клавишами `1`
  (хор вступает) и `2` (хор смолкает);
- щелчок по ленте — перемотка;
- «Сохранить метки» записывает их в `data/cues.json`; они относятся к одной
  записи и с другой не применяются. «Найти заново» возвращает найденные по
  громкости.

Главное — первая метка: на ней в зале вспыхивает свет и Большой паук открывает
глаза.

## Слова

Всё, что написано в ролике, лежит в [`data/words.json`](data/words.json) и
правится без кода:

| поле | что это |
|---|---|
| `to` | обращение на странице благодарности — **сейчас пусто, впишите имя и отчество** |
| `thanks`, `lines` | заголовок и строки прощания (появляются по одной) |
| `signature`, `group`, `place` | подпись |
| `floors` | лабораторные: номер, название, строка о работе и вещи паучат (`props`); на этаже их по две |
| `bubbles` | реплики Пафнутия на последней странице |
| `music`, `credits` | титры; `{count}` заменяется числом паучат в труппе |

Если сыграет другая запись, поправьте строку `music`.

Вещи в `props` раздаются паучатам под табличкой слева направо — поэтому
`"card:EN", "card:→", "card:DE"` читается как фраза:

| вещь | что это |
|---|---|
| `lens` | лупа |
| `page` | лист документа |
| `card:надпись` | табличка с любой короткой надписью |
| `scroll`, `scissors`, `note` | длинный свиток, ножницы и короткая записка |
| `horn` | рог глашатая; пока паук поёт, из него идёт звук |
| `mic` | микрофон |
| `wear:headphones` | не в ноге, а на голове: наушники (так же — `hat`, `glasses`, `bow`, `cap`) |

## Как устроено

```
run.py                     запуск
poklon/
  server.py                сервер на http.server: страница, запись, слова, метки
  show.py                  поиск записи, чтение слов, проверка меток
  web/index.html           страница
  web/static/
    score.js               партитура: спектр, поиск хора, путь лифта
    spider.js              паук: геометрия ног, виды, цвета, гардероб, рисунок
    troupe.js              труппа и декорации: кто где висит и что проезжает мимо
    stage.js               сцена: кадр для секунды t
    show.js                показ: загрузка, часы, клавиши, репетиция
data/words.json            слова
music/                     сюда кладётся запись
tests/                     проверки
tools/                     кадры ролика и проверочная дорожка
```

Паук — та же модель, что в «Слухаче» и «Глашатае» (ноги из двух сегментов,
колено считается по положению стопы), перенесённая с SVG на canvas: в кадре
бывает больше сотни пауков сразу. Дети отличаются пропорциями одной модели —
крестовик, паучонок, птицеед, сенокосец, скакун, чёрная вдова, аргиопа,
бокоход — и цветом.

Кадр — функция секунды: в сцене ничего не копится от кадра к кадру. Поэтому
ролик можно ставить на паузу, мотать и снимать любой кадр. Часы ролика — часы
звука, так что рты и свет не расходятся с музыкой, даже если вкладка
подтормаживает.

## Проверка

```
python -m pytest tests -q
```

Расчёты без рисунка (партитура, геометрия паука, расстановка) написаны так,
чтобы работать и в node; их проверки — `tests/*.test.js`, из pytest они
запускаются сами. Сервер проверяется во временных папках.

Посмотреть ролик, не просматривая его целиком:

```
python tools/make_test_track.py        проверочная дорожка data/test_track.wav (не музыка: размеченный звук)
python run.py --music data/test_track.wav --no-browser
python tools/frames.py                 кадры ключевых моментов → frames/
```

Для `pytest` и снимков нужны пакеты из `requirements.txt`; самому ролику — нет.
