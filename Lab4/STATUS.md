## Как пересобрать всё заново

Команды выполняются в папке `Lab4/`:

```bash
python -m pytest tests -q
python tools/train.py --check          # точность анализатора → report/analyzer.json
python tools/evaluate.py               # оценка и графики → report/evaluation.json, eval_*.png
python run.py --no-browser             # в отдельном окне, для снимков
python tools/screenshots.py            # report/screens/*.png
python tools/make_diagrams.py          # схемы
python tools/make_report.py            # ОтчётЕЯзИИС47.docx
```
