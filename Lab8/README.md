# «Глашатай» — синтез немецкой речи для научных текстов

Лабораторная работа № 8, **вариант 3**:

| параметр | значение |
|---|---|
| система | синтеза речи |
| язык | немецкий |
| предметная область | научные статьи по computer science |

Система читает вслух немецкие научные тексты по информатике. Текст можно
набрать, вставить из буфера обмена, открыть из файла (TXT, HTML, PDF, DOCX)
или по адресу страницы, взять из другой программы Windows — скопировав или
выделив мышью — и указать мышью на любой веб-странице. Перед синтезом
система разбирает текст: числа, годы, порядковые, единицы, сокращения,
аббревиатуры, формулы, ссылки и английские термины она переписывает
словами так, как их произнёс бы немецкий докладчик, и решает, где кончается
предложение. Читает выбранным голосом с заданными темпом, громкостью,
высотой, живостью интонации и паузами; звучащее предложение подсвечивается.

Голосов четыре вида:

* **нейросетевые** — Piper (VITS, ONNX), немецкие дикторы Thorsten, Kerstin,
  Eva K и Thorsten с восемью манерами (спокойно, весело, сердито, сонно,
  шёпотом…); работают без сети;
* **собственный формантный синтезатор**, написанный с нуля: правила
  произношения, длительности и мелодия, источник голоса и каскад
  резонаторов по схеме Клатта — голоса Карл, Клара и Пафнутий;
* **голоса Windows** (Microsoft Speech API), если установлены немецкие;
* **голос браузера** (Web Speech API) — в Edge и Chrome это сетевые
  «естественные» голоса.

Сверх задания:

* **«Мой говорящий Пафнутий»** — паук из прошлых работ в роли кота из
  «Говорящего Тома»: повторяет сказанное в микрофон смешным голосом (писк,
  бас, робот, шёпот, эхо), отзывается на тычки в голову, глаза, брюшко,
  любую из восьми ног и нить, качается на паутине, ест мух, спит, когда
  выключен свет, и, как в «Моём говорящем Томе», голодает, устаёт и скучает;
  забота даёт уровни, уровни открывают гардероб. Говорит по-немецки, в
  облачке — перевод;
* **словарь произношения** — пользователь записывает, как читать трудное
  слово, и запись сразу действует везде;
* **проверка на слух**: разборчивость голосов измеряет распознаватель речи.

Глашатай — тот, кто громко и внятно объявлял указы на площади, читая
написанное за тех, кто прочесть не мог. Название продолжает ряд «Арахна»,
«Толмач», «Изборник», «Драгоман», «Слухач».

## Быстрый старт

```bash
pip install -r requirements.txt
python tools/get_voices.py        # голоса Piper: 4 модели, ≈ 225 МБ, один раз
python run.py
```

Откроется браузер на `http://127.0.0.1:8083/` — на «Чтеце» уже лежит пример;
нажмите «Читать» (или Ctrl+Enter). Без голосов Piper система работает на
собственном синтезаторе.

```bash
python run.py --no-browser               # только сервер
python run.py --port 8080                # другой порт
python run.py --voice formant:karl       # голос по умолчанию
python run.py --no-desktop               # без буфера обмена и горячих клавиш
```

| переменная | значение |
|---|---|
| `GLASHATAI_VOICE` | голос по умолчанию (`piper:de_DE-thorsten-medium`) |
| `GLASHATAI_DESKTOP` | `0` — не следить за буфером и не брать горячие клавиши |
| `GLASHATAI_COMPANION` | `0` — убрать паука Пафнутия и его вкладку |
| `GLASHATAI_HOST`, `GLASHATAI_PORT` | адрес и порт сервера (`127.0.0.1`, `8083`) |
| `GLASHATAI_VOICES_DIR` | каталог голосов Piper (по умолчанию `voices/`) |
| `GLASHATAI_STATE_DIR` | где хранить словарь пользователя и настройки (`data/`) |
| `GLASHATAI_CACHE_DIR` | где хранить готовые реплики Пафнутия (`data/cache/`) |

Нужны Chrome или Edge. Немецкие голоса Windows ставятся в «Параметрах» →
«Время и язык» → «Речь»; без них раздел «Голоса Windows» в списке пуст.
Микрофон («Мой говорящий Пафнутий») браузер даёт только адресам
`127.0.0.1` и `localhost`.

## Как система читает текст

```
текст ─► абзацы и предложения ─► токены ─► нормализация ─► произношение ─► синтезатор ─► обработка звука ─► звук
           segment.py              normalize.py   lexicon.py      engines/       dsp.py
```

1. **Абзацы.** Пустая строка разделяет абзацы всегда, одиночный перевод
   строки — только после точки, у заголовка или пункта списка: иначе это
   перенос внутри абзаца, как в тексте из PDF. Строка «# …» и короткая строка
   без точки перед текстом — заголовок (после него пауза абзаца).
2. **Предложения.** Точка — конец предложения, только если дальше пробел и
   заглавная буква, и это не точка сокращения («z. B.», «vgl.», «S. 12 f.»),
   не порядковое число («im 19. Jahrhundert»), не инициал («J. von Neumann»),
   не номер раздела («1.2. Abschnitt»). Сокращения вроде «usw.» и порядковое
   число могут кончить предложение — если следующее слово из тех, с которых
   начинаются фразы («Die», «Danach», «Es»…). Предложение длиннее
   400 знаков делится на части по «;», «:» и запятым ближе к середине — они
   читаются без паузы.
3. **Токены.** Предложение разбирается одним регулярным выражением на
   25 видов токенов (26 — со словарём пользователя): адрес, почта, ссылка на источник, дата, время,
   сокращение, десятилетие, диапазон, номер версии, порядковое, дробь,
   степень, число с единицей, буквы с цифрами, аббревиатура, слово, знаки.
   Каждый токен помнит место в исходном тексте: по нему подсвечивается
   прочитанное.
4. **Нормализация** — у каждого токена запись словами и произношение (см.
   ниже). Правила, которым нужны соседи, — второй проход: падеж порядкового
   по слову перед ним, «ein/eine/einem» перед существительным, «eine Million»
   после «1 Mio.».
5. **Произношение.** Английские термины (сочетания, слова и части сложных
   слов — «Softwareentwicklung», «Quellcode»), имена и аббревиатуры
   заменяются записью немецкими буквами из словарей; словарь пользователя
   важнее всего.
6. **Синтезатор** получает предложение в нужном ему виде: собственный — с
   отметками ударения, Piper — текстом, а слова из словарей — готовыми
   фонемами в `[[ … ]]`, голос браузера — словами, но английские термины как
   написаны (его голоса знают английский сами).
7. **Обработка звука.** Тишина по краям срезается, уровень приводится к
   −18 дБ по громким участкам, края плавно нарастают и затухают; темп и
   высоту, которых движок не умеет, досчитывают WSOLA и передискретизация.
   Громкость на странице — усилитель в звуковом потоке браузера: меняется на
   ходу, ничего не синтезируя заново.

Пока звучит предложение, следующие два уже синтезируются; готовые
предложения хранятся в памяти (до 96 МБ звука) — шаг назад и повтор не
синтезируются заново.

| количество | 1024 · 1.000.000 · 12 345 | tausendvierundzwanzig · eine Million · zwölftausenddreihundertfünfundvierzig |
| год (1100–1999 без единицы) | 1954 | neunzehnhundertvierundfünfzig |
| десятилетие | 1950er-Jahren · 80er | neunzehnhundertfünfziger Jahren · achtziger |
| порядковое — окончание по слову перед ним | im 19. · die 2. · ein 2. · vom 12. bis 14. Juni | im neunzehnten · die zweite · ein zweiter · vom zwölften bis vierzehnten Juni |
| дробь, проценты, версия | 3,5 % · 3/4 · Python 3.11 | drei Komma fünf Prozent · drei Viertel · Python drei Punkt elf |

| дата, время, отношение, диапазон | am 12.03.2021 · 14:30 Uhr · 3:1 · 5–10 | am zwölften März zweitausendeinundzwanzig · vierzehn Uhr dreißig · drei zu eins · fünf bis zehn |
| сокращение (83 в словаре) | z. B. · d. h. · vgl. Abb. 3 · S. 12 f. · 3 Mio. | zum Beispiel · das heißt · vergleiche Abbildung drei · Seite zwölf folgende · drei Millionen |
| аббревиатура по буквам | CPU · HTTP · URIs · RDFa | Zeh Peh Uh · Hah Teh Teh Peh · Uh Err Ihs · Err Deh Eff Ah |
| аббревиатура как слово (правило) | DARPA · ADALINE · NEPOMUK | Darpa · Adaline · Nepomuk |
| аббревиатура по словарю (94) | RAM · JSON · OWL · C++ | Ramm · Dschäison · Aul · Zeh plus plus |
| буквы с цифрами, римские | IPv6 · W3C · x86 · Fortran II | Ih Peh Fau sechs · Weh drei Zeh · Iks sechsundachtzig · Fortran zwei |
| формула | O(n log n) · x ≥ 0 · 2^10 · n² · α | Oh von Enn log Enn · Iks größer gleich null · zwei hoch zehn · Enn Quadrat · Alpha |
| английский термин (≈ 210 в словаре) | Deep Learning · Cloud · Softwareentwicklung | Diep Lörning · Klaud · Softwär-entwicklung |
| адрес, почта, ссылка | https://de.wikipedia.org/… · info@x.de · [12] | Deh Eh Punkt wikipedia Punkt org · info at x Punkt Deh Eh · (пропускается) |
| знаки | & · § 9a · ~5 | und · Paragraf neun Ah · ungefähr fünf |

Аббревиатура читается по буквам, если в ней меньше четырёх букв или
согласные стоят так, как в немецком слове не бывают («HTML», «DSGVO»);
иначе — как слово. Названия букв записаны так, как звучат («Zeh», «Peh»,
«Uh»), ударение — на последней.

Английские термины записаны немецкими буквами так, как их произносит
немецкий докладчик, с апострофом перед ударным слогом: «Fräimwörk»,
«Kom'pjuter», «Mä'schien 'Lörning». Термин узнаётся и в сложном слове: в
начале («Softwareentwicklung») и в конце («Quellcode», «Netzwerkserver»), если
оставшаяся часть не короче 3–4 букв; короткие термины, которые бывают концом
немецких слов («Bot» — «Angebot», «Hub» — «Hubraum»), так не ищутся.

Точка внутри предложения для синтезатора — конец фразы: eSpeak NG на ней
роняет интонацию. Поэтому в тексте для синтезатора внутри предложения
остаются только запятые, а точка — в конце.

Каждое правило выключается в настройках — так слышно, как читал бы
синтезатор без него.

## Правила произношения

Собственному синтезатору нужны фонемы, и для слов из словарей их же получает
Piper. Немецкая орфография почти однозначна, произношение выводится
правилами (`phonetics/g2p.py`):

1. **Исключения** — 267 служебных и частых слов с непредсказуемым ударением
   или долготой («System», «Programm», «Methode», «Mathematik», «der», «hat»).
2. **Состав слова.** Сложное слово делится по известным основам — в конце
   («Betriebs|system»), в начале с соединительным элементом
   («Klasse-n|bibliothek», «Speicher|medien») и после суффикса с
   соединительным «s» («Sicherheits|maßnahmen»); главное ударение — на первой
   части (140 основ). Отделяются безударные приставки (be-, ge-, ver-, ent-…), ударные
   (an-, auf-, aus-, zusammen-…) и суффиксы (-heit, -keit, -lich, -chen…).
   Числительные-композиты разбираются на части: neun|zehn|hundert|vier|und|fünfzig.
3. **Буквы в звуки** длинными сочетаниями вперёд: «tsch», «sch», «chs», «ch»,
   «ck», «ei», «eu», «ie»… Гласная долгая — двойная, с «h», «ie», в открытом
   слоге и перед «шумная + плавная» («Pro-gramm»); краткая — перед двойной
   согласной, «ck», «tz», «ch» (кроме «Buch», «Sprache»…), скоплением
   согласных. «ch» после a, o, u, au — [x], иначе [ç]; в начале слова перед
   a, o, r, l — [k]. «r» после гласной — [ɐ̯], безударное «-er» — [ɐ]. «e» в be-,
   ge- и в конечном слоге — [ə]. b, d, g на конце слога — [p], [t], [k];
   «-ig» на конце — [ɪç]; «s» перед гласной — [z], «st/sp» в начале основы — [ʃt],
   [ʃp]; «v» в немецких словах — [f], в иноязычных — [v]; «-tion» — [tsjoːn].
4. **Слоги и ударение.** Слог начинается с наибольшего допустимого немецкого
   сочетания согласных и не переходит границу частей слова. Ударение — на
   первом слоге основы; 63 иноязычных окончания (-ion, -ität, -ieren, -ie,
   -ur, -ell, -al, -ent, -anz, -or…) переносят его на себя.

На странице «Чтец» вкладка «Транскрипция» показывает транскрипцию каждого
слова (МФА) и для сравнения — транскрипцию eSpeak NG, а также «партитуру»
первого предложения для собственного синтезатора.

## Синтезаторы

### Нейросетевые голоса Piper

Piper (проект Rhasspy) — модели VITS: нейросеть превращает фонемы сразу в
звук, без отдельного вокодера; работает на процессоре без сети, в 10–15 раз
быстрее реального времени. Фонемы строит встроенный eSpeak NG.

| голос | модель | частота | заметка |
|---|---|---|---|
| Thorsten | de_DE-thorsten-medium | 22 кГц | основной |
| Kerstin | de_DE-kerstin-low | 16 кГц | |
| Eva K | de_DE-eva_k-x_low | 16 кГц | 20 МБ |
| Thorsten (эмоции) | de_DE-thorsten_emotional-medium | 22 кГц | восемь манер: спокойно, весело, удивлённо, сердито, брезгливо, сонно, пьяно, шёпотом |

Что пришлось сделать вокруг Piper:

* **eSpeak NG не открывает данные по пути с кириллицей**
  («C:\Users\Никита\…») — путь заменяется коротким именем Windows (8.3), а
  если его нет, данные копируются в каталог голосов;
* **английские термины и аббревиатуры** уходят готовыми фонемами `[[ … ]]`:
  запись из словаря («'Klaud») транскрибируется собственными правилами и
  переводится в обозначения eSpeak (r в начале слога — [r], после гласной —
  [ɾ], «-er» — [ɜ], «aː» — [ɑː], знак ударения перед гласной). Сам eSpeak
  прочёл бы «Cloud» как [klˈuːt], «Machine Learning» — как
  [maxˈiːnə lˈeːaɾnɪŋ];
* **старые модели** (Kerstin, Eva K) обучены на «ç» одним знаком, а eSpeak
  отдаёт его разложенным (c + седиль): модель пропускала седиль и говорила
  [c] вместо [ç]. Система собирает такие знаки обратно;
* **темп Piper нелинеен**: length_scale 0,5 ускоряет речь не вдвое, а в
  1,5 раза, и быстрее ×1,4 модель почти не говорит. Длина берётся по таблице
  калибровки (измерено на трёх предложениях), остаток темпа досчитывает
  WSOLA. Высоту Piper не меняет — её сдвигает обработка звука;
* «живость» — разброс тембра и длительностей в модели (noise_scale
  0,2–1,15, noise_w 0,3–1,3; 0,5 — значения Piper по умолчанию).

### Собственный формантный синтезатор

Так работали первые синтезаторы — MITalk, DECtalk, — и так устроен eSpeak:
речь строится не из записей, а из модели «источник — фильтр»
(`engines/formant.py`).

* **Партитура** (`phonetics/prosody.py`): у каждой фонемы собственная
  длительность (долгая гласная 135 мс, краткая 80, шва 50, «s» 100…); ударный
  слог длиннее (×1,15), безударный короче (×0,75), согласные в скоплении
  короче (×0,8), последний слог перед паузой растягивается (×1,4); на
  запятой пауза 170 мс, на «;» — 260. Мелодия: тон плавно снижается от 1,12
  до 0,92 среднего за предложение; на ударном слоге каждого знаменательного
  слова — подъём (последний в фразе — выше), служебные слова акцента не
  получают; в конце утверждения тон падает, вопроса — поднимается, перед
  запятой — чуть приподнят.
* **Источник голоса** — импульсы Розенберга с частотой основного тона
  (щель плавно открывается за 2/3 открытой фазы и быстро закрывается),
  производная — излучение губ; немного шума в открытой фазе — придыхание.
* **Источник шума** — белый шум: придыхание после «p, t, k» и «h» идёт через
  форманты следующей гласной, шум щелевых — через параллельную ветвь.
* **Каскад**: носовой нуль и полюс, пять формантных резонаторов Клатта
  (`y = A·x + B·y₋₁ + C·y₋₂`). **Параллельная ветвь**: шум через резонаторы
  2–6 с собственными усилителями — так задаётся спектр шумных: у «s» энергия
  около 6 кГц, у «ʃ» — 2,5–4, у «x» — 1–2.
* **Цели фонем**: форманты 24 качеств немецких гласных (включая краткие
  напряжённые и неслоговое [ɐ̯]; дифтонги — из двух целей),
  места образования согласных («локусы» — куда тянутся форманты соседних
  гласных), громкости голоса, шума и придыхания, спектры взрывов. Параметры
  меняются каждые 5 мс и сглаживаются (форманты — окном 35 мс): так
  получаются переходы между звуками, по которым слух узнаёт согласные.

Голоса: **Карл** (112 Гц), **Клара** (205 Гц, тракт на 14 % короче) и
**Пафнутий** (255 Гц, тракт на 24 % короче — маленькое существо).

Калибровка. Форманты гласных проверены анализом LPC синтезированного звука
(расхождение с целью — в пределах нескольких процентов). Первая версия
говорила почти без согласных: глухие щелевые были на 39–49 дБ тише
гласных. Усиления шумовой ветви и придыхания подобраны так, чтобы «s»,
«ʃ», «f», «ç», «x», «h» были тише гласных на 11, 11, 22, 15, 17 и 20 дБ, как
в живой речи, — после этого доля ошибок распознавания на наборе для
настройки упала с 91 до 80 %. Остальные пробы (паузы между словами,
гортанная смычка, сила взрыва, звонкая смычка, ширина сглаживания, темп)
меняли её в пределах разброса и оставлены как были. Набор для настройки —
24 предложения статьи «Compiler»; в проверку он не входит.

### Голоса Windows

System.Speech вызывается через PowerShell: один процесс живёт всё время
работы системы и получает задания построчно (JSON) — запуск PowerShell на
каждое предложение занимал бы секунду, а так первое предложение ждёт ≈ 1 с,
следующие — десятки миллисекунд. Темп задаёт сама Windows (число от −10 до
10: 10 — втрое быстрее), высоту — обработка звука. В списке — только
немецкие голоса; если их нет, страница говорит, где их установить.

### Голос браузера

Web Speech API (`speechSynthesis`): система отдаёт браузеру уже
нормализованное предложение, браузер говорит сам и сообщает о каждом слове
— звучащее слово подсвечивается (CSS Custom Highlight API, без изменения
разметки). В Edge это сетевые «естественные» голоса Microsoft (Katja,
Conrad…), в Chrome — Google Deutsch. Для других программ и сохранения в файл
голос браузера заменяется голосом по умолчанию.

## Чтение из других программ

Страница «Из других программ»:

* **Читать всё, что скопировано.** Система трижды в секунду спрашивает у
  Windows номер версии буфера обмена (`GetClipboardSequenceNumber`) и,
  когда он меняется, читает текст (`CF_UNICODETEXT`). То, что лежало в буфере
  до включения, не читается.
* **Горячие клавиши.** `RegisterHotKey` в своём потоке с очередью сообщений.
  По **Ctrl+Alt+R** система ждёт, пока отпустят Ctrl и Alt (иначе её Ctrl+C
  стал бы Ctrl+Alt+C), сама нажимает Ctrl+C в активной программе, забирает
  выделенное и **возвращает в буфер прежнее содержимое**. **Ctrl+Alt+S** —
  замолчать. Если сочетание занято другой программой, страница об этом
  скажет.
* **Где звучит.** Если открыт «Чтец», текст приходит туда по потоку событий
  сервера (Server-Sent Events) и читается с подсветкой; если нет — прямо из
  колонок (`winsound`), причём синтез идёт на предложение впереди звука.
* **Закладка «Глашатай, читай»** — для любой веб-страницы. Закладка
  добавляет на страницу сценарий `pointer.js`: он рисует внизу панель (в
  теневом DOM — стили сайта её не задевают), подсвечивает абзац под
  указателем мыши и читает его по щелчку; выделенный фрагмент читается
  вместо абзаца. Звук страница просит как обычный аудиофайл:
  `http://127.0.0.1:8083/api/say.wav?text=…`; длинный абзац делится на куски
  по предложениям, и следующий кусок загружается, пока звучит текущий.
  Попробовать: «страница-пример» `/demo` — «чужой сайт» со статьёй о
  семантической паутине. Браузер может спросить разрешение обращаться к
  локальной сети — звук идёт с этого компьютера. Сайты со строгой политикой
  безопасности (CSP) закладку не пускают — на них поможет Ctrl+Alt+R.

Всё на ctypes (user32.dll, kernel32.dll), без дополнительных пакетов; в
других системах буфер и горячие клавиши отключаются, закладка работает.
Голос и настройки — те, что выбраны на «Чтеце» (страница отправляет их
серверу, тот хранит их в `data/settings.json`).

(+3,0); бас — 74 % (−4,8 при заданных −5).

### Выводы

1. **Нормализация — главное, что система добавляет к синтезатору.** Сам
   eSpeak NG правильно читает лишь 23 % трудных мест: «1954» — как
   количество («eintausend neunhundert…»), «z. B.» — как две фразы,
   «12 GB» — как «Ge Be», «am 3. Mai» и «12:30 Uhr» — как набор чисел. На
   слух доля ошибок на таких фразах падает с 35 до 15 %, на сокращениях — с
   36 до 6 %.
2. **Оставшиеся ошибки на слух — во многом ошибки распознавателя.** Он пишет
   «neunzehnhundert vierundfünfzig» двумя словами, а эталон — одним, и это
   две ошибки (поэтому у годов 31 %); так же «syntax baums» против
   «Syntaxbaums». Разборчивость голосов Piper выше, чем 18–22 %: заметная
   часть ошибок — разбиение сложных слов и редкие термины («Parser» —
   «pasa»).
3. **Нейросетевые голоса разборчивее собственного вчетверо** (18–22 %
   против 74–78 %). Собственный синтезатор строит речь из правил — без
   единой записи голоса — и звучит как робот: распознаватель, обученный на
   живой речи, улавливает служебные слова и основы («syntax baums …
   attributen versehen»), но путает согласные. Из трёх его голосов
   разборчивее высокий и быстрый «Пафнутий».
4. **Все голоса быстрее речи в 10–16 раз** (RTF 0,06–0,10): предложение
   готово за 0,4–0,6 с, а пока оно звучит, синтезируются следующие — пауз на
   синтез нет.
5. **Настройки работают как обещано.** Темп Piper нелинеен и упирается
   примерно в ×1,4; после калибровки и досчёта WSOLA измеренный темп
   совпадает с заданным до сотых. Громкость точна. Высоту собственный
   синтезатор меняет точно (±0,1 полутона); у Piper сдвиг вверх на 10–15 %
   меньше заданного: на ровном тоне обработка точна (тест), на речи — нет;
   вероятная причина — растяжение WSOLA окнами 40 мс речи с меняющимся
   тоном.
6. **Быстрая речь теряет разборчивость**: ×1,5 Kerstin выдерживает (24 %),
   Thorsten — хуже (35 %), на ×2 ошибок у обоих вдвое-втрое больше.
   Thorsten на ×2 — это его предел ×1,4 и растяжение WSOLA поверх: двойная
   обработка слышна.
7. **Голоса Пафнутия смешные и в основном понятные**: писк и робот почти не
   мешают распознаванию, бас и эхо — мешают (низкий медленный голос и
   повторы), что для игры и задумано.

### Что улучшило бы систему

* собственный синтезатор: параметры фонем, извлечённые из записей (а не из
  таблиц), уравнения локусов для переходов взрывных, обучаемая длительность —
  или переход к конкатенации дифонов;
* правила произношения: морфологический словарь для деления сложных слов и
  ударения неотделяемых приставок («über|**setz**en»), долгота в
  производных («Er|**geb**nis»);
* нормализация: согласование числительных по падежу и роду по
  морфологическому анализу, а не по окончаниям; различение года и количества
  по смыслу («1500 Einträge»);
* английские слова вне словаря — по определению языка слова и английским
  правилам чтения;
* Piper: модель thorsten-high, сдвиг тона без изменения формант (PSOLA,
  вокодер WORLD), синтез по частям внутри длинного предложения;
* закладка — расширением браузера: его не останавливает политика
  безопасности сайтов;
* оценка слушателями (MOS, тест на разборчивость) и распознавателем
  побольше (Whisper): малая модель Vosk строже человека.

### Чего проверка не показывает

Разборчивость измерена распознавателем, а не людьми: он не знает тему
текста, не догадывается по смыслу и считает ошибкой каждое иначе
разделённое сложное слово, — это нижняя оценка. Эталон нормализации
составлен автором системы. Интерфейс проверен в браузере без окна;
микрофон «Говорящего Пафнутия» заменял искусственный звук — с живым
микрофоном система не проверялась.

## Мой говорящий Пафнутий

Вкладка `/talking`. Паук висит на нити посреди комнаты — окно, полка с
книгами, лампа под потолком — и делает то же, что кот из «Говорящего Тома».

**Повторяет за вами.** «Говори — повторю» включает микрофон. Начало и конец
фразы находит детектор по громкости: шум комнаты отслеживается, пока вы
молчите; фраза начинается, когда три кадра (20 мс) из пяти громче шума на
12 дБ, и кончается после 700 мс тишины (не дольше 8 с). Пока вы говорите,
паук поднимает передние лапы — прислушивается. Запись (16 кГц, с 300 мс до
начала фразы, чтобы не пропал первый согласный) уходит на сервер и
возвращается передразниванием:

| голос | как сделан |
|---|---|
| писк | тон на 7 полутонов выше и чуть быстрее (×1,12) — классический «Том» |
| бас | тон на 5 полутонов ниже, чуть медленнее |
| робот | LPC: по кадрам 25 мс найден фильтр речевого тракта (18 коэффициентов, с расширением полос), его возбуждает ровный поток импульсов 120 Гц |
| шёпот | тот же фильтр, возбуждённый шумом |
| эхо | тон на 3 полутона выше и три затухающих повтора через 190 мс |

Пока паук говорит, микрофон не слушается — иначе он передразнил бы сам себя.
Без микрофона ему можно написать: скажет вслух своим голосом.

**Говорит по-немецки.** У паука 54 реплики на 25 поводов, каждая — с
переводом в облачке и манерой: на тычок в голову — „Au!“ (удивлённо), на
третий подряд — „Mir ist schwindlig“ (пьяно), спящий — „Pssst, ich schlafe“
(шёпотом). Реплики синтезирует голос Thorsten с этой манерой, поднятый на
шесть полутонов, а без Piper — собственный голос «Пафнутий». Готовые
реплики хранятся на диске и при запуске синтезируются заранее, в фоне.

**Тычки** (мышью или пальцем). Куда попали, страница решает по геометрии
модели: глаза, голова, брюшко — эллипсы, ноги — отрезки бедра и голени из
последней позы, нить — над телом.

* голова — „Au!“ и паук вздрагивает; три раза за 4 секунды — кружится голова;
* глаз — моргает и сердится;
* брюшко — щекотно, смеётся;
* нога — паук поджимает **именно эту** ногу (у модели восемь ног с
  вычисляемыми коленями — см. «Слухач»);
* нить — дёргается вниз и пружинит;
* провести по брюшку или голове — погладить: довольные глаза, сердечки;
* схватить и утащить в сторону — раскачать: маятник
  θ″ = −(g/L)·sin θ − трение, длина нити меняется вместе с указателем;
  раскачанный сильно — кружится голова;
* семь тычков за 6 секунд — обида: паук краснеет, говорит „Jetzt reicht es!“
  и уходит вверх по нити, а через пять секунд возвращается.

**Кнопки**: 🦟 муха (кружит вокруг паука, он следит глазами, ловит передними
лапами и жуёт; сытый — отказывается), 🥁 тарелки (подпрыгивает по нити,
растопырив ноги), 🎂 торт (крем на мордочке, через пару секунд паук
вытирается), 🕸 паутина (плетёт — за спиной появляется паутина, с каждым
разом больше), 💡 свет (спит, храпит, бодрость растёт), 📖 почитай (надевает
очки и читает фразу из научной статьи). Звуки — тарелки, хруст, храп, трель
— синтезирует сама страница (Web Audio), без файлов.

**Потребности**, как в «Моём говорящем Томе»: сытость, бодрость и
настроение. За минуту бодрствования сытость падает на 0,6, бодрость — на
0,4, настроение — на 0,5; во сне бодрость растёт на 5 в минуту. Потребности
убывают и пока вкладка закрыта (не больше суток). Голодный или скучающий
паук грустит и сам напоминает о себе; уставший зевает, а без сил засыпает.
Забота даёт опыт: девять уровней, со второго по седьмой открывают гардероб —
цилиндр, очки, бабочку, наушники, корону, шапочку магистра (шляпа одна:
надетая снимает другую). Всё хранится в браузере.

`GLASHATAI_COMPANION=0` убирает паука, вкладку и его голос; чтение, голоса и
настройки работают по-прежнему (проверяется тестом в отдельном процессе).

### Структуры данных

| структура | назначение |
|---|---|
| `Token` | кусок текста: место, как написан, запись словами, произношение, вид |
| `Sentence`, `Paragraph`, `Document` | предложение (с токенами и видом: утверждение, вопрос), абзац, разобранный текст |
| `ReadingOptions` | какие правила чтения включены |
| `Abbreviation`, `Entry`, `Lexicon`, `UserLexicon` | сокращение, запись словаря произношения, все словари, словарь пользователя |
| `Syllable`, `Pronunciation` | слог (фонемы, ударение), произношение слова |
| `Phone`, `Score` | звук партитуры (длительность, мелодия), партитура предложения |
| `FormantVoice` | голос собственного синтезатора: тон, длина тракта, форма импульса |
| `Voice`, `Settings`, `Audio`, `Spoken` | голос любого движка, настройки чтения, звук, синтезированное предложение |
| `DesktopState`, `Desktop` | буфер обмена и горячие клавиши |
| `GoldCase` | случай эталона нормализации |

## Сценарии и тесты

```bash
python tools/get_voices.py --vosk     # голоса Piper и модель Vosk
python tools/evaluate.py              # проверка (≈ 25 минут) и графики
python tools/evaluate.py --quick      # по 3 предложения из статьи, без темпов
python tools/screenshots.py           # снимки экрана (система должна работать)
python -m pytest tests -q             # тесты
```

Тесты проверяют числительные; нормализацию — весь эталонный набор, падежи
порядковых, род и число единиц, контекст чисел, места токенов в тексте,
выключение правил, словарь пользователя; деление на абзацы и предложения;
словари и разбор сложных слов; правила произношения на 40 словах,
сложные слова, числительные, записи с ударением, обозначения eSpeak;
партитуру (темп, ударение, удлинение, вопрос, служебные слова); формантный
синтезатор — тон голосов, сдвиг тона и темп, форманты гласных по LPC,
калибровку уровней шумных согласных, спектры щелевых; обработку звука —
WAV, тон, WSOLA, сдвиг тона, громкость, LPC, эффекты Пафнутия; движки,
откат на голос по умолчанию, кэш, паузы, вставку фонем для Piper,
калибровку темпа, голоса Windows; извлечение текста из HTML, DOCX, PDF;
буфер обмена и горячие клавиши (в Windows); веб-интерфейс целиком;
выключатель паука; проверочные наборы.

В браузере без окна (Edge, протокол DevTools, сервер — в том же процессе)
проверяются правила на JavaScript (паузы проигрывателя, деление текста
закладкой, потребности и уровни паука, детектор фразы) и живые страницы:
«Чтец» читает, подсвечивает, ставит на паузу и продолжает; выключенное
правило меняет разбор; статья читает предложение под указателем; паук
различает голову, брюшко, глаз и нить, поджимает ногу, ест муху, обижается
и уходит, спит, помнит опыт после перезагрузки; закладка на «чужой» странице
читает абзац по щелчку; словарь добавляет слово и меняет чтение.

Без пакета piper-tts или голосов пропускаются тесты Piper, без модели Vosk —
тест разборчивости, не в Windows — тесты буфера и горячих клавиш, без Chrome
или Edge — тесты в браузере. Словарь, настройки и реплики Пафнутия тесты
пишут во временные каталоги. С живым микрофоном и на слух система
проверялась только в той мере, в какой это сделал распознаватель.
